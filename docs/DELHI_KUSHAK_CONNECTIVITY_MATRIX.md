## Reading rules

1. **MODEL_ONLY ≠ as-built.** Rows whose only elevation/geometry is Appendix-XII-derived describe the 2018 model, not field reality (mission rule; GSDL design inventory likewise).
2. **"NONE DOCUMENTED" is a finding**, not a gap in this matrix — no surveyed invert, junction coordinate, or as-built section exists publicly for any listed structure.
3. **Conflicts are carried, not averaged**: the C1–C4 conflict table in `DELHI_KUSHAK_CONNECTIVITY_AUDIT.md` §3 governs every row that touches a conflict.
4. No row uses map proximity, OSM, or basin membership as connection proof.
